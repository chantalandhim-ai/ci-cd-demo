# CI/CD Pipeline Demo

This project demonstrates a CI/CD pipeline using GitHub Actions.

## Features
- Automated build and test on each push
- Continuous Integration using GitHub Actions
- Docker image build integration
- Pipeline failure debugging and resolution

## Tech Stack
- Node.js
- GitHub Actions
- Docker

## Pipeline Workflow
1. Code is pushed to repository
2. GitHub Actions pipeline is triggered
3. Dependencies are installed
4. Tests are executed
5. Docker image is built

- Managing YAML configurations
- Integrating Docker into CI workflows
